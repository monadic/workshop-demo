    helm install runs the chart that passed every local check. It does not 
    wait, because the pods are not going to start.

Tip:

  Watch the deployment status using the command: kubectl get pods -w --namespace shop

Services:

  echo Primary: shop-db-mysql.shop.svc.cluster.local:3306

Execute the following to get the administrator credentials:

  echo Username: root
  MYSQL_ROOT_PASSWORD=$(kubectl get secret --namespace shop shop-db-mysql -o jsonpath="{.data.mysql-root-password}" | base64 -d)

To connect to your database:

  1. Run a pod that you can use as a client:

      kubectl run shop-db-mysql-client --rm --tty -i --restart='Never' --image  docker.io/bitnami/mysql:9.4.0-debian-12-r1 --namespace shop --env MYSQL_ROOT_PASSWORD=$MYSQL_ROOT_PASSWORD --command -- bash

  2. To connect to primary service (read/write):

      mysql -h shop-db-mysql.shop.svc.cluster.local -uroot -p"$MYSQL_ROOT_PASSWORD"
